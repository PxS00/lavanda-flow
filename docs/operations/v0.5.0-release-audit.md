# v0.5.0 release audit

## Candidate provenance

- Branch: `release/v0.5.0`.
- Validated `develop` ancestor: `b63e37c032531ee7c7b73059f1df93d32244a7eb` (#138).
- The release candidate includes the focused exact-decimal correction merged as
  `62c1ec1` (#171). No feature work was added after the release branch was cut.

## Release evidence

- **Exact decimal transport:** #171 resolved the release blocker by serializing HTTP `BigDecimal` values as
  plain JSON decimal strings and retaining strings through Angular DTOs, forms, and lossless display. Quoted
  requests are canonical; representative legacy numeric requests remain accepted. OpenAPI documents the
  `string`/`decimal` representation. This intentionally corrects v0.4 JSON numeric quantity responses.
- **Architecture:** Spring Modulith verification passed. The audit found the approved module graph
  (`production -> catalog, inventory`; `inventory -> catalog, suppliers`) and no prohibited cross-module
  JPA, repository, or infrastructure imports.
- **Backend validation:** `./mvnw verify` passed with 401 tests, no failures, errors, or skips. PostgreSQL 17
  Testcontainers and Flyway integration coverage passed.
- **Frontend validation:** `pnpm lint`, `pnpm test` (47 files, 235 tests), and `pnpm build` passed.
- **Historical migrations:** released V1-V9 files and checksums remained compatible. The v0.4.0 upgrade
  audit on disposable PostgreSQL 17 accepted V1-V9, applied only V10-V13, and preserved the legacy inventory
  probe with null production-reference fields. Required production relations were present.
- **Fresh install:** a separate empty disposable PostgreSQL 17 database applied successful Flyway history
  V1-V13 without manual intervention.
- **Initial inventory:** #138 validated the frozen external source checksum, zero-write `DRY_RUN`, guarded
  atomic `APPLY`, five-column `Retirada` adjustment semantics, and PostgreSQL-only operation after import.
  The approved effective date is `2026-09-06`; see
  [V1 operational readiness](v1-operational-readiness.md).

## Known constraints and warnings

- Angular's initial bundle remains above the configured budget; this is non-blocking and unchanged.
- Existing Maven/Testcontainers/Springdoc and build-tool warnings remain non-blocking.
- The application must not be exposed to the public internet until authentication and authorization are
  selected and implemented. This release audit does not make that deployment decision.

## Conclusion

The release candidate is ready for the release pull request to `main`, subject to the final validation gates
recorded for the release branch. The audit proved forward schema upgrade compatibility and legacy-data
preservation only; it did not prove an operational rollback from v0.5.0 to v0.4.0 after production activity.
