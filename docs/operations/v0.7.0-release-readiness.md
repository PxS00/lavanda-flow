## Release-scope operator audit

The six included issues are integrated and covered by the existing backend/frontend tests and routes.

- Catálogo and Estoque remain separate Angular concepts (`/catalog` and `/inventory`) with separate
  navigation and workflows.
- Stock workspaces provide `all`, `finished-products`, `essences`, `inputs`, and `packaging` routes.
  The finished-products workspace includes bulk and packaged presentations; the backend remains the
  single inventory/batch authority.
- `Registrar saída` uses the existing automatic FEFO endpoint and response allocations. FEFO, expiry,
  eligibility, and available-stock decisions remain backend-authoritative.
- Inventory-item maintenance is available through catalog registration/detail/edit workflows and keeps
  stable references and history protections.
- Supplier maintenance is available through Angular list/detail/edit workflows and is non-destructive.
- Low-stock and expiration alerts link to the existing catalog, stock, receipt, and operational-item
  workflows; no alert-specific stock authority was added.
- Production history exposes paginated list and stable detail navigation in Angular. Detail data comes
  from persisted execution/source-consumption records and links to existing batch/genealogy workflows.
- User-visible application content remains pt-BR.

Every v0.7 operator-facing endpoint introduced by the included issues has Angular consumption:

- inventory-item update and stock-list endpoints: catalog edit and grouped stock pages;
- supplier update endpoint: supplier edit page;
- alert endpoints: actionable alerts page;
- production execution history/detail endpoints: history list/detail pages; and
- backup automation: maintainer/operations scripts, intentionally not an application UI.

Intentionally non-UI contracts remain legitimate lower-level or technical interfaces:

- direct batch entry and direct batch withdrawal endpoints are lower-level contracts; normal operators
  use the receipt and backend-authoritative FEFO workflows;
- the legacy current-stock read is retained as a lower-level compatibility read; operator stock views
  use the grouped stock/overview contracts;
- Actuator/metrics and local OpenAPI/Swagger endpoints are technical/maintainer diagnostics; the
  operational profile does not expose them as operator workflows.

No backend business rule was duplicated into Angular. Angular sends backend-confirmed requirements and
allocations, uses quoted decimal DTO fields, and does not calculate FEFO, expiry, eligibility, formula
scaling, genealogy, or lot allocation.
